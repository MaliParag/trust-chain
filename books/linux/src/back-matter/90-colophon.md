# Colophon

*The Linux Trust Chain* (Volume III of *The Platform Trust Chain Series*) is authored in CommonMark Markdown and produced through the series' deterministic multi-volume publishing pipeline (`mdBook`, `tools/mdbook-trustchain.mjs`, `tools/gen-summary.mjs`, `tools/diagram_lib.py`, `tools/gen-seo.mjs`, `tools/build-pdf.mjs`, and `tools/audit_book.py`).

**Visual Identity and Typography.** Volume III shares the unified *Platform Trust Chain Monograph* interior across web and print editions. Sustained body prose is set in `Georgia` for long-form print and screen legibility, paired with system sans-serif headings, five-coordinate `Overview` specification cards, proportional `<colgroup>` tables with zero horizontal clipping, and `KaTeX` mathematical typesetting. All sixty-three architectural figures are bespoke vector `SVG` schematics generated by `books/linux/tools/gen_diagrams.py` atop `tools/diagram_lib.py`, mechanically verified for strict orthogonal routing, masked edge pills, and zero text, card, or arrowhead collisions. The print and digital `PDF` edition (`the-linux-trust-chain.pdf`) is rendered at a `7.00 x 9.25 in` technical monograph trim via headless Chromium W3C CSS `@page` pagination with full-bleed vector front and back covers and native bookmark outlines.

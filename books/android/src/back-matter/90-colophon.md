# Colophon

*The Android Trust Chain* (Volume IV of *The Platform Trust Chain Series*) shares the unified *Platform Trust Chain Monograph* interior across web and print editions, pairing `Georgia` long-form serif body typography with system sans-serif section headers, five-coordinate `Overview` specification cards, proportional `<colgroup>` bordered tables, and `SF Mono` / `Menlo` code blocks.

**Pipeline.** Every chapter is authored in CommonMark Markdown with build-time KaTeX mathematical typesetting and built through the shared multi-volume publishing pipeline (`tools/gen-summary.mjs`, `tools/mdbook-trustchain.mjs`, `tools/diagram_lib.py`, `tools/build-pdf.mjs`, and `tools/audit_book.py`) governed by the craft invariants in `editorial.md`. All sixty-three architectural vector diagrams in `books/android/tools/gen_diagrams.py` are programmatically generated and seven-way collision- and orthogonality-verified on every build.
